# 単一対象の正解注釈と評価

この評価では、撮影セッションごとに **同じ 1 個の対象物**を追います。同じクラスの物体が複数ある場合にも、最初に決めた対象の `object_id` を維持してください。他の cup に切り替わった検出は、正解対象との位置が合わなければ誤検出になります。

## 注釈 CSV

UTF-8 の CSV を使います。bbox は元動画座標のピクセル値で、拡大後の座標ではありません。

```csv
session_id,frame_id,object_id,label,visible,x,y,width,height,reviewed
experiment_01,1,cup_01,cup,1,100,200,30,50,1
experiment_01,2,cup_01,cup,,,,,,,0
experiment_01,3,cup_01,cup,0,,,,,1
```

- `frame_id`: 元映像の記録フォルダ `recordings/<記録ID>/frames.csv` の `frame_id` と一致する番号（上の階層の推論ログ `frames.csv` の `frame` 列ではない）。この実装の新規録画・動画再生は1始まり。セッション内で重複不可。
- `object_id`: 対象物を表す固定の文字列。セッション中に変更不可。
- `label`: モデル出力と一致するクラス名。セッション中に変更不可。
- `visible=1`: 対象が見えている。既定規則では部分遮蔽でも同定できる可視部分を囲む。難しいフレームは無理に採点せず `reviewed=0` とする。この規則は最終評価前に固定する。
- `visible=0`: 完全遮蔽または画面外で、対象が見えない。bbox は空欄可。
- `reviewed=1`: 人が確認済み。見える対象には正しい bbox が必須。
- `reviewed=0`: 未確認・判断不能。bbox の仮入力があっても評価に使わない。

未記載フレームと `reviewed=0` はともに採点対象外です。**未注釈を「物体がいない」という正解にしないでください。** 自動提案した bbox も人が確認するまで `reviewed=0` のままにします。

CSV だけでは元映像の幅・高さが分からないため、右端・下端が画像外にはみ出しているかは評価器では検証できません。注釈確認時に確認してください。負の座標、非有限の数値、0 以下の幅・高さ、重複、対象 ID の変更などはエラーになります。

## 評価の定義

予測 CSV は、方法ごとに全フレームを出力します。未検出でも行を残し、bbox を空にしてください。`observed=0` は検出なし、または位置予測だけを表します。位置予測の bbox が正解に重なっていても、正検出には数えません。

確認済みかつ可視の正解に対し、クラスが一致し、IoU が指定の閾値以上なら TP（正検出）です。標準閾値は 0.5 です。クラス違い・IoU 不足の観測 bbox は FP と FN の両方を増やします。完全不可視なのに検出を出した場合も FP です。

- recall = TP / 可視正解フレーム数。可視正解が 0 なら `null`。
- precision = TP / 採点対象の観測検出数。観測検出が 0 なら `null`。
- `mean_matched_iou`: TP だけの平均 IoU。TP が 0 なら `null`。
- `mean_visible_iou_including_misses`: 可視正解に対する平均 IoU。未検出・クラス違いを 0 とする。
- `id_switches`: 連続する正検出で ID が変わった回数。間に未検出・遮蔽があっても、同じ対象の ID が変われば数える。ID 不明の検出はこの計算から除外し、ID 付与率を別途表示する。
- `dominant_id_fraction_of_matches`: 最も多かった 1 つの ID の TP 数 / 全 TP 数。
- `dominant_id_visible_recall`: その ID の TP 数 / 可視正解フレーム数。これは IDF1 ではない。

サイズ別 recall は **正解 bbox の面積**で分類します。small は 32² px 未満、medium は 32² px 以上 96² px 未満、large は 96² px 以上です。評価する動画の解像度も合わせて記録してください。

見失い区間は、確認済みの可視フレームが連続している範囲で数えます。未注釈・未確認・完全不可視・フレーム番号の飛びで区間を区切ります。再検出時間は、最初の未検出フレームの動画時刻から次の TP の動画時刻までです。再検出せず区間が終わった場合は `censored=true` とし、最後の未検出フレームまでの秒数は下限値として記録します。単発の区間が 0 秒でも「損失なし」という意味ではありません。

確認済みの可視正解があるのに予測行が欠落している場合は FN とし、`missing_prediction_frames` に明示します。時刻が欠けた見失い区間の長さは推測せず `null` にします。

処理時間は全予測行の `inference_ms` の中央値・95 パーセンタイル・最大値です。`source_sample_rate_fps` は動画時刻に対するフレーム率で、PC の実行速度ではありません。精度未評価でも処理時間だけは集計できます。

## 結果を読むとき

セッション・方法ごとに結果を分けます。注釈の確認率、予測行の欠落、不可視区間、対象サイズ分布を先に確認してください。未確認フレームしかない場合は `evaluation_status=no_reviewed_annotations` とし、精度の値は出しません。

これは単一対象の評価です。mAP / MOTA / HOTA / IDF1 として報告しないでください。最終評価前に注釈規則、IoU 閾値、学習・調整・評価のセッション分割を固定し、同じ元動画・同じフレーム・同じ正解で比較します。
