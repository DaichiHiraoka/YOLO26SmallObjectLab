# 実装検証記録 2026-09-23

この記録は研究用ソフトウェアの動作検証です。小物体追跡の研究成果、学習モデルの実データ精度、ライブ速度の測定ではありません。

## 検証した範囲

- 入力画素を保持したPNG記録、時刻と番号、非同期保存、欠落の明示、10 GiB容量制限、終了時の保存。
- 全比較方式への同一フレーム供給、通常/局所推論で共通の信頼度閾値、未検出フレームの出力。
- 単一対象のIDと短時間の位置予測、SRで回復した結果による状態更新。予測位置だけを検出成功に数えないこと。
- 未確認注釈を採点しないこと、誤検出/未検出/ID変化/遮蔽/欠落行/時間/サイズ別評価。
- 合成データでの候補収集、注釈確認、データ結合、学習、保存、読み込み、別セッションへの選択器適用。
- 学習/調整/評価セッションの重複拒否、train限定の標準化、GT一致による学習、未学習候補の除外。
- 画面に描いた最大bboxと測定CSVの対象が一致すること。

pytest: 85件成功。pyflakes: 指摘なし。合成データはテスト専用で、実データ学習済みモデルとして公開・配置していません。

## GPU実行

NVIDIA GeForce RTX 5070、torch 2.13.0+cu130、Ultralytics 8.4.86、OpenCV 5.0.0で、ローカルYOLO26重みを使った実行を確認しました。

7月23日の過去の枠付き保存画像4枚を、ソフトウェア接続確認のためだけに使用しました。入力記録から4方式の比較、候補ログ、未確認注釈に対する評価まで完了し、欠落0枚でした。x2/x4/x8のFSRCNN処理と局所YOLO推論も明示的に実行しました。

過去の画像には描画済みbbox/文字があり、現在の閾値でcupの正検出を確認するデータにはなりません。この結果から検出精度やSRの効果は主張しません。未確認注釈のrecallはnullになることを確認しています。

詳細ログは `outputs/research_validation_20260923/validation.json` と `comparison/run.json` に保存します。計測時点のソースと設定のハッシュも残ります。
